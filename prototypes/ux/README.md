# Кликабельный UX-прототип B03

Статус: низкодетальный прототип для согласования, не приложение

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python3 -m http.server 4173 --directory prototypes/ux
```

После запуска откройте `http://127.0.0.1:4173`.

## Что проверяется

- телефон сотрудника: динамический QR;
- телефон водителя: подтверждение и отклонение строки;
- iPad кладовщика: приемка партии и погрузка;
- офис: центр контроля с отклонениями;
- состояние без сети;
- крупные зоны касания;
- понятные тексты подтверждений и ошибок.

## Ограничения

- используются только тестовые данные;
- QR является визуальной имитацией;
- серверные операции имитируются в браузере;
- данные не сохраняются после обновления страницы;
- это не каркас production-приложения и не выбирает окончательный визуальный стиль.
