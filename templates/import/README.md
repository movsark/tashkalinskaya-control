# Шаблоны массового импорта

## Шаблон v1.0

Файл `Шаблон_массового_импорта.xlsx` предназначен для предпросмотра и
подтвержденной загрузки товаров и недельных норм.

Листы:

- `Инструкция` — порядок работы и ошибки;
- `Товары` — новые/обновляемые карточки товаров;
- `Нормы` — одна строка на территорию, день вывоза, товар и период;
- `Справочники` — допустимые категории, единицы, территории и дни.

Шаблон не содержит реальных товаров и норм фабрики. В него запрещено добавлять
ФИО, телефоны, адреса, зарплаты, полуфабрикаты и другие данные вне границ MVP.

Исходная рабочая книга не является допустимым шаблоном системы. Для первой
миграции используется отдельный преобразователь, профиль которого описан в
`docs/B07_SOURCE_WORKBOOK_PROFILE.md`.
