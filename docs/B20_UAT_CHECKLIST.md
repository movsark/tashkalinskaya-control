# B20. Чек-лист фабричной приёмки MVP

Статус: подготовлен; выполняется владельцами процессов на staging и по ступеням B21.

Для каждого сценария фиксируются дата, участники, устройство, результат,
фактическое время, номер дефекта и подпись владельца процесса.

## Сквозной рабочий день

- [ ] Администратор создаёт тестовых сотрудников, роли и терминал.
- [ ] Сотрудник приходит по динамическому QR; повтор токена отклоняется.
- [ ] Ответственный делает ручную отметку отсутствующего телефона с причиной.
- [ ] Водитель территории 9 видит выпуск среды для пятничного рейса.
- [ ] Водитель предлагает постоянное и разовое изменение; администратор решает.
- [ ] После 10:00 изменение следующего производственного дня запрещено.
- [ ] Магазин отправляет заказ до 10:00; позднее изменение проходит заявкой.
- [ ] План учитывает нормы, изменения, магазин, возврат и свободный остаток.
- [ ] При неподтверждённой инвентаризации план создаётся с тревогой.
- [ ] Ответственный распределяет задания; кондитер выпускает обычную и ночную партию.
- [ ] Невыполнение и брак требуют причину; фото работает по правилу причины.
- [ ] Кладовщик принимает полную, частичную и отклонённую партию.
- [ ] Группа четырёх водителей параллельно подтверждает строки погрузки.
- [ ] Ошибка строки возвращается на исправление; завершение требует две стороны.
- [ ] Инвентаризация выявляет намеренное расхождение и создаёт компенсацию.
- [ ] Кладовщик принимает годный возврат; администратор распределяет часть пула.
- [ ] Повреждённый возврат превращается в запрос списания и проходит решение.
- [ ] Администратор вручную сверяет внешний номер документа 1С/Agent Plus.
- [ ] Руководитель видит тревоги, контрольный экран и формирует Excel/PDF.
- [ ] Бухгалтер получает только табельный отчёт.
- [ ] Повтор отправки при плохой связи не создаёт дубль ни одной операции.

## Устройства и печать

- [ ] Samsung: установка PWA, WebAuthn, QR, камера, push.
- [ ] iPhone: установка PWA, WebAuthn, QR, камера, push.
- [ ] iPad: терминал, камера, восстановление сессии.
- [ ] Офисный браузер: администрирование и отчёты.
- [ ] Целевой принтер: A4 без обрезки и с читаемой кириллицей.
