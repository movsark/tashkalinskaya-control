# B03.2. Единая дизайн-система MVP

Статус: в работе, первый сквозной срез реализован 03.08.2026.

## 1. Зачем сделан этот срез

В рабочих модулях появилось много ссылок, цветов и самостоятельных
карточек. На телефоне это создавало ощущение длинной формы без понятной
точки возврата. Цель первого среза — дать всем ролям одинаковую простую
оболочку, не меняя уже реализованные бизнес-правила.

## 2. Принятое направление

- светлая нейтральная основа и один основной тёмно-зелёный цвет;
- цвет используется для действия, ошибки или важного статуса, а не для украшения;
- на экране есть одно явное главное действие;
- основная навигация похожа на привычное мобильное приложение;
- каждая роль видит только доступные ей разделы;
- повторные ссылки в шапках скрыты, переходы собраны в одном месте;
- целевые размеры: iPhone/Samsung, iPad и офисный экран.

## 3. Единая навигация

После входа сотрудник попадает на настоящий главный экран. Внизу постоянно
доступны четыре пункта:

1. **Главная** — понятная точка возврата.
2. **Работа** — главный раздел конкретной роли: цех, склад, маршрут, магазин или табель.
3. **События** — уведомления со счётчиком непрочитанных.
4. **Меню** — все остальные разрешённые разделы в компактном выдвижном окне.

На экранах входа, активации и табельного планшета эта навигация скрыта, чтобы
не мешать одному целевому сценарию.

## 4. Базовые токены

| Назначение | Значение | Правило |
| --- | --- | --- |
| Фон | `#f5f5f1` | Общий фон без декоративных пятен |
| Карточка | `#ffffff` | Рабочие группы и списки |
| Основной | `#17483d` | Главное действие и активная навигация |
| Основной текст | `#1f2422` | Заголовки и данные |
| Вторичный текст | `#707873` | Пояснения и метаданные |
| Граница | `#dfe2de` | Тихое разделение групп |

Минимальная высота основной кнопки — 48 px. Карточки и поля имеют единые
закругления; тени используются только для плавающей навигации и модального меню.

## 5. Ролевые главные действия

| Роль | Главная работа |
| --- | --- |
| Администратор | Сотрудники |
| Водитель | Маршрут водителя |
| Продавец магазина | Заказ фирменного магазина |
| Кладовщик | Склад |
| Кондитер / ответственный за цех | Производство |
| Бухгалтер / руководитель | Контроль табеля |
| Сотрудник только для табеля | Мой табель |

## 6. Что реализовано в коде

- настоящий главный экран для авторизованного сотрудника;
- ролевая карта разделов и выбор главной работы;
- нижня навигация и ролевое меню;
- единые цвета, карточки, кнопки, заголовки и отступы для всех рабочих экранов;
- переход на главный экран после входа, регистрации и повторного открытия PWA;
- адаптация к безопасным зонам iPhone и мобильным размерам.

## 7. Критерии приёмки этого среза

- после входа администра открывается «Главная», а не список сотрудников;
- с любого рабочего экрана можно одним нажатием вернуться на «Главную»;
- меню не показывает запрещённые роли разделы;
- нижняя навигация не перекрывает кнопки и конец формы;
- на ширине 390, 834 и 1440 px нет горизонтального выхода за рамки;
- первоначальный экран входа остаётся понятен без инструкции;
- production-сборка, lint, typecheck и браузерные сценарии проходят.

## 8. Что остаётся до закрытия B03.2

- короткая полевая проверка всех ключевых ролей на планшете и в перчатках;
- поэкранная уплотняющая доработка по результатам пилота;
- проверка сетевых, пустых, ошибочных и конфликтных состояний каждого модуля;
- финальная приёмка владельцем после ролевого UAT B20/B21.
