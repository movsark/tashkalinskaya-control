# Приемочные сценарии B18

## A18-01. Контроль на дату

Руководитель выбирает дату и видит план, выпуск, свободный склад, незавершенную
погрузку, открытую инвентаризацию, порчу, табель и критичные тревоги. Переход с
карточки открывает соответствующий рабочий модуль.

## A18-02. Воспроизводимый файл

Пользователь заказывает Excel, после чего в исходных таблицах появляется новая
операция. Готовый файл содержит только данные зафиксированного снимка и его время.

## A18-03. Excel

Файл открывается без предупреждений, имеет заголовок, параметры, закрепленную строку
колонок, автофильтр, читаемые ширины, числовые форматы и итоговую строку.

## A18-04. PDF и печать

PDF открывается, кириллица отображается, заголовки таблицы повторяются на страницах,
поля не обрезаются при печати A4.

## A18-05. Роли и персональные данные

Бухгалтер видит и формирует только табель. Руководитель и администратор видят весь
каталог. Сотрудник без этих ролей получает `403`, включая прямую ссылку на файл.

## A18-06. Фоновая очередь

Два worker обрабатывают несколько заданий без двойной генерации. После временного
сбоя задание повторяется, после третьей ошибки получает FAILED с безопасным текстом.

## A18-07. Архив и контрольная сумма

Реестр показывает автора, период, формат, число строк, срок хранения и SHA-256.
Скачанный файл совпадает с сохраненной контрольной суммой.

## A18-08. Сверка

Итоги движений, план/факт, приемки, погрузки, возврата, порчи и инвентаризации
совпадают с подтвержденными первичными таблицами и складским журналом.

## A18-09. Ограничения

Диапазон более 366 дней, неизвестный отчет и выгрузка более 10 000 строк отклоняются
понятной ошибкой, не создавая задания.

## A18-10. Адаптивность

На 390×844 каталог и метрики идут одной колонкой, на 834×1112 — двумя, на офисном
экране — сеткой; горизонтального переполнения страницы нет.
