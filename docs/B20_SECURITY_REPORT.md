# B20. Отчёт безопасности MVP

Статус: автоматическая проверка B20.1 и публичный smoke Timeweb B20.2 пройдены;
открыт сетевой дефект staging-БД, независимый pentest и проверка целевых устройств
остаются воротами перед промышленным запуском.

## Проверено автоматически

- все рабочие routes закрыты аутентификацией по умолчанию;
- меняющие routes требуют CSRF, кроме явных WebAuthn/activation церемоний;
- фабричные роли и step-up сверяются с фиксированной матрицей;
- hostile Origin и похожие домены отклоняются точным сравнением;
- Helmet выставляет `X-Content-Type-Options` и `X-Frame-Options`;
- приватный route без сессии возвращает стабильный `401`;
- сессии, WebAuthn challenge, отзыв устройства и rate limit имеют unit/integration tests;
- QR короткоживущий, одноразовый и не содержит ФИО;
- XLSX и фото имеют ограничения размера/типа и безопасные имена;
- фото приватны, ответы имеют sandbox CSP;
- аудит и confirmed ledgers защищены от update/delete;
- секреты и приватные файлы проверяются перед каждым PR;
- production-зависимости проверяются `npm audit` с порогом high.

## Исправлено в B20.1

`F20-001 / P0`: production API собирался, но не стартовал из-за отсутствующих
импортов `IdentityModule` в восьми функциональных модулях. Дефект обнаружен новым
Playwright startup-тестом, исправлен явными imports и закрыт регрессией CI.

Origin middleware вынесен в тестируемую функцию. Добавлены случаи домена-префикса
и домена с допустимым именем в подстроке.

## Проверено на внешнем staging 02.08.2026

- HTTPS web, manifest, service worker, live и readiness отвечают штатно;
- приватная сессия без авторизации возвращает `401`;
- запрос с посторонним Origin возвращает `403`;
- security headers и correlation ID присутствуют;
- версия приложения совпадает с зафиксированным commit.

Обнаружен `F20-002 / P1`: публичный IPv4 staging-БД включён, а групп сетевого
экрана нет. До B21 приложение нужно безопасно переключить на приватную точку и
отключить публичный IPv4 либо временно ограничить его строго необходимыми
адресами. Резкое отключение без смены строки подключения запрещено, потому что
оно остановит staging.

## Остаётся до production

- независимая проверка по OWASP ASVS 5.0 с доступом к staging;
- DAST авторизованных ролей и проверка object-level authorization;
- WebAuthn и Web Push на Samsung, iPhone и iPad;
- авторизованная проверка cookie и ролевых маршрутов на внешнем reverse proxy;
- тест S3 policy, коротких ссылок и lifecycle;
- тест ротации всех секретов без потери активных данных;
- анализ журналов на отсутствие payload, токенов и лишних персональных данных;
- утверждение срока хранения с бухгалтером.

В кодовой базе открытых P0/P1 после B20.1 нет. В окружении открыт `F20-002 / P1`;
он блокирует B21. Отчёт не заменяет независимую проверку production-окружения.
