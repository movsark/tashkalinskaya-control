# ADR-0011. Граница будущей интеграции

- Статус: принято по общей рекомендации владельца
- Дата: 01.08.2026
- Связанный блок: B19

## Решение

Внутренняя система сохраняет собственные UUID, канонические коды и бизнес-
правила. Идентификаторы 1С/Agent Plus хранятся в отдельном версионируемом
словаре. Обмен выполняется только через версионированный JSON-конверт,
интеграционный inbox/outbox и отдельный адаптер без прямого SQL-доступа.

Обе внешние системы в MVP отключены. Ручная сверка остаётся рабочим процессом,
а автоматический обмен требует отдельного проекта и решения владельца.

## Причины

Модель и возможности конкретной версии 1С/Agent Plus пока не обследованы.
Копирование неизвестной внешней модели создало бы зависимость MVP, риск дублей и
возможность потерять подтверждённую операцию при сбое внешней системы.

Идемпотентный inbox/outbox отделяет фиксацию фабричной операции от доставки.
Версия контракта, контрольная сумма и карантин делают повторы и ошибки
наблюдаемыми, не разрешая переписывать историю.

## Последствия

- подтверждённые операции продолжают работать при недоступности внешней системы;
- внешний код можно заменить новой версией соответствия без смены внутреннего UUID;
- payload обмена после постановки в очередь неизменяем;
- REST и файловый транспорт реализуются одинаковым интерфейсом адаптера;
- перед активацией нужны обследование, утверждённая JSON Schema и пилот;
- до этого 1С/Agent Plus не влияют на критерии готовности MVP.
