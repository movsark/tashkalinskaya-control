# ADR-0003. Календарь, территория 9 и свободный остаток

- Статус: принято
- Дата: 30.07.2026
- Связанные решения: A-08, A-09

## Решение

Производственная дата и дата вывоза хранятся отдельно.

Для территории 9 администратор может создать исключение: производство в среду для пятничного маршрута. Исключение создается на конкретные даты и не меняет общее правило для всех недель.

Свободный складской остаток не распределяется автоматически. Кладовщик или администратор вручную назначает товар территориям. Система:

- показывает доступное количество;
- не позволяет распределить одну единицу дважды;
- фиксирует автора и время;
- разрешает исправление только через компенсирующую операцию.

## Последствия

План должен объяснять, какие строки появились из нормы, заказа магазина, складского распределения или календарного исключения.
