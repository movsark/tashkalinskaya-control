# ADR-0007. Отсечка 10:00 и воспроизводимый план

- Статус: принято по общей рекомендации владельца
- Дата: 31.07.2026
- Связанный блок: B09

## Решение

Норма относится к дню вывоза. Опубликованный календарь однозначно связывает
каждую дату вывоза с производственной датой.

Ежедневно в 10:00 `Europe/Moscow` scheduler выбирает ближайшую открытую
производственную дату после текущей локальной даты и публикует один план для
всех связанных дат вывоза.

- момент 10:00 входит в закрытый период;
- разовая норма заменяет постоянную, а не складывается с ней;
- количества задаются абсолютными значениями;
- свободный остаток распределяют только кладовщик или администратор;
- без подтвержденной инвентаризации используется системный остаток с тревогой;
- без отправленного заказа магазина используется ноль с тревогой;
- расчет выполняется только из неизменяемого snapshot;
- одинаковый snapshot и версия движка дают одинаковый результат;
- опубликованный план изменяет только администратор новой версией;
- прошлые версии и подтвержденные операции не редактируются.

## Причины

Понятие «план на завтра» неоднозначно из-за четверга без производства, пятницы
без вывоза, праздников и территории 9. Явная связь дат делает результат
проверяемым и позволяет планировать несколько дат вывоза одной
производственной датой.

Snapshot исключает гонку, когда норма, остаток или заказ меняются во время
расчета, и позволяет воспроизвести любую опубликованную цифру.

## Последствия

- календарь должен быть опубликован заранее и пройти preflight;
- B10, B12 и B14 предоставляют версионируемые входы до фазы B;
- B11 получает план производственной даты и сохраняет ссылки на его версию;
- B15 подключает возврат отдельным источником исполнения нормы;
- отсутствие календарной связи блокирует план, а отсутствие пересчета/заказа
  не блокирует, но эскалируется.
